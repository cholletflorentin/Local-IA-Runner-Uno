# Local IA Runner — bêta Uno Platform

Ce dépôt contient le code source de la bêta multi-plateforme Uno de Local IA Runner, publié séparément de l'application WinForms stable.

Le projet C# et XAML se trouve dans [`UnoApp`](UnoApp/README.md). Il vise Windows, Linux, macOS et Android. Le workflow GitHub Actions construit les quatre archives desktop ainsi que l'APK Android, puis les publie en préversion GitHub.

Pour les instructions d'installation, l'utilisation du serveur llama.cpp intégré et le développement, consulte [UnoApp/README.md](UnoApp/README.md).
